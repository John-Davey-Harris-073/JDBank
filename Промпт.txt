Ты — опытный Fullstack-разработчик на Python. Мне нужно разработать с нуля веб-приложение для личного учета финансов под названием "JDBank". 

Оно должно быть кроссплатформенным (адаптивный дизайн для десктопных и мобильных браузеров, таких как Firefox и Safari). 
Приложение будет развернуто на бесплатной платформе Render. Разработка ведется на Windows 10.

Технический стек:
- Backend: Python 3.11+ (используй FastAPI или Flask — выбери наиболее подходящий для быстрой сборки и легкого деплоя).
- База данных: SQLAlchemy (SQLite для локальной разработки на Windows, PostgreSQL для продакшена на Render через переменные окружения).
- Frontend: Чистый HTML5, CSS (Tailwind CSS через CDN для адаптивности под мобильные устройства) и Vanilla JavaScript (минимальный, для AJAX-запросов). Без сложных сборщиков (npm/webpack), так как фронтенд должен отдаваться сервером Python (Server-Side Rendering с шаблонами Jinja2).

Бизнес-логика и требования к функционалу:
1. Система аутентификации:
   - Сессия должна быть защищенной (хэширование паролей с помощью bcrypt/werkzeug).
   - Гостевой доступ запрещен: при открытии любого URL неавторизованного пользователя редиректит на страницу Login/Register.
   - Форма входа (Username, Password) и форма регистрации.

2. Управление счетами и валютами:
   - Возможность создавать несколько счетов (например: "Наличные", "Карта BYN", "Крипто-кошелек").
   - Поддержка любых валют (пользователь сам вводит тикер при создании счета, например: BYN, USD, BTC, EUR).
   - Отображение текущего баланса по каждому счету.

3. Транзакции:
   - Создание транзакций: доход, расход, перевод между своими счетами.
   - Поля транзакции: Счет-источник, Счет-получатель (для переводов), Тип (Доход/Расход/Перевод), Сумма, Категория (например, Еда, Зарплата), Дата/Время, Комментарий.
   - Автоматический пересчет баланса счетов при добавлении/удалении/изменении транзакций.

4. Дизайн:
   - Минимализм: не должно быть ничего лишнего.
   - Цвета: оранжевый, белый и совсем чуть-чуть черный.

Что тебе нужно сделать СЕЙЧАС (Этап 1 — Архитектура и База данных):
1. Напиши структуру проекта для Windows 10.
2. Предоставь код файла `requirements.txt`.
3. Напиши код для инициализации базы данных и моделей SQLAlchemy (`User`, `Account`, `Transaction`). Учти связи "один ко многим" (у одного пользователя много счетов и транзакций).
4. Напиши базовый файл конфигурации (`config.py`), который переключает SQLite/PostgreSQL в зависимости от наличия переменной окружения `DATABASE_URL`.

Пиши чистый, готовый к копированию код без сокращений. После этого мы перейдем к реализации эндпоинтов и интерфейса.
